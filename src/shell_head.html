    Route settings

    Group size only affects the mob-kill estimator; quest XP is the same for every member. To change it partway, use the Group control under the map, which adds a step at the selected point.

    Kill XP while questing

    Uses your group size at each step. Dungeon mobs give their Era XP (elite ×2) divided by this number; 3.5 mirrors the dungeon quest boost and fits 20 XP per player from a level 16 mob in a 5-player group.

    Import / export route

    Objective numbers in .complete follow Questie's order (kills, objects, items). Check them in-game on quests with mixed objectives.

    To load a route: choose Open file… or paste a route file here, then Import. It is added as a new route.

    Zone map images

    Add your own screenshots of the in-game zone maps and they'll be drawn in place when you zoom in. Crop each screenshot to the map artwork only, with no window frame, so it lines up with the zone's edges. Images stay in this browser.

    Import a RestedXP guide

    Paste a guide or choose a .lua or .txt file. Files with several RegisterGuide blocks become separate guides. The guide is drawn as a ghost route you can join and leave from your own route.

    Restore from a backup

    The planner keeps a copy of your routes each day you open it (the last 7 days). Restoring adds the routes from that day as copies; nothing you have now is removed.
